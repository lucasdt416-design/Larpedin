# Delarp: LinkedIn Truth Translator

Install: open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**, and choose this `extension` folder.

Use:
- Select text on any page (LinkedIn, X, email), right-click, choose **🔍 Delarp this**.
- A card at the top right shows what they actually meant. Copy it or close it with ×.
- Or click the toolbar icon, paste a post and press **Delarp**.
- Change the API URL in `API_BASE` at the top of `background.js` and `popup.js`.
